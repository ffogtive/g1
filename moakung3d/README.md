# 모아쿵! 3D — 물리엔진 데모

> **가설:** 물리엔진은 *움직임*을, 규칙(`js/rules.js`)은 *판정*을 맡는다. 이렇게 나누면 진짜로 튀고 무너지는 3D 케이크 파괴와
> "미리보기 = 실제 결과(튀어나가는 개수·남은 재료·횟수)"를 함께 지킬 수 있다.
> 케이크가 1개여도 **층 케이크(넘친 힘 버려짐)·젤리 코팅(절반이 튐)·단단함·묵직한 재료(힘 2배)**가 레벨마다 섞이면,
> "딱 맞게 모으기 = ★★★, 전부 쏟기 = 별이 줄거나 실패"가 성립한다.

## 실행

- 설치·서버 없이 `moakung3d/index.html`을 브라우저로 엽니다. three.js·cannon-es·모델이 모두 저장소 안에 있습니다.
- 한 파일로 묶기: `node moakung3d/tools/build-single.js out.html` (약 2.8MB)

## 한 판의 흐름 (레벨 12개, 케이크 1개씩)

1. **지도**에서 레벨을 고릅니다. 깨면 다음 레벨이 열립니다.
2. **쓸어 담기:** 빈 바닥을 꾹 누른 채 문지르면, 분홍 원 안의 재료가 하나의 혼합 덩어리로 붙습니다.
3. **개수 맞춤:** 하단 `[− n +]`로 정한 개수에서 딱 멈춥니다. 가운데를 누르면 켜고 끕니다.
4. **조준:** 덩어리를 케이크 위로 옮기면 덩어리가 윗면에 붙고, 카드에 다음이 나옵니다:
   - 이 층이 부서지는지, 몇 % 남는지
   - 덩어리 힘(묵직한 재료 ×2)
   - 튀어나갈 개수와 남는 재료
   - 넘쳐서 버려질 힘
5. **쿵:** 손을 떼면 자동으로 들어 올렸다가 **진짜 물리로** 떨어집니다(낙하 1번). 케이크 조각이 날아가고 재료가 튑니다.
   - 쓴 재료의 1/3(젤리 코팅은 1/2)이 쟁반 밖으로 나갑니다. 가벼운 재료부터 나갑니다.
6. **놓기·잡기·톡:** 케이크 밖에서 놓으면 덩어리가 그 자리에 놓입니다(횟수 그대로). 잡아 옮기면 더 줍지 않고, 톡 치면 흩어집니다.
7. **피날레:** 케이크를 다 부수면 남은 낙하와 재료가 보너스 점수가 됩니다(캔디크러시식). 점수로 별 1~3개를 받고 도감에 기록됩니다.

| 레벨 | 케이크 | 특징 |
|---|---|---|
| 1–3 | 커스터드 푸딩 · 레몬 무스 · **딸기 로즈 티 케이크(Meshy 모델)** | 말랑, 개수 맞춤, 묵직한 재료 2배 |
| 4–6 | 초코 가나슈 · 마카롱 탑 · 베리 치즈케이크 | 단단함(작은 덩어리는 흠집) |
| 7–9 | 무지개 크레이프(2층) · 3단 생일(3층) · 왕관 초코 타르트(2층) | 층 케이크(넘친 힘은 아래층에 안 감) |
| 10–12 | 젤리 푸딩 · 젤리 치즈케이크 · 젤리 3단 케이크 | 젤리 코팅(절반이 튐) |

`node moakung3d/tools/balance.js`가 레벨마다 다음 성질을 전수 검사합니다:
- 딱 맞게 → ★★★
- 2개씩 넘쳐도 ★★★, 4개씩 넘쳐도 클리어
- 전부 쏟으면 ★★, 여러 층이면 실패
- 묵직한 재료를 몰라도 클리어 가능

## 3D 모델 바꾸기 (Meshy·블렌더)

- `world.js`의 `buildCake()`가 케이크를 만드는 유일한 자리입니다.
- GLB 모델은 `buildModelCake()`가 **높이 구간(층) × 각도 구간(10조각)**으로 자동 분할해 같은 금·폭발 연출을 씁니다.
- 큰 모델 줄이기: `npx @gltf-transform/cli optimize in.glb out.glb --compress quantize --texture-compress webp --texture-size 1024 --simplify-ratio 0.014`
  - 지금 들어간 딸기 로즈 티 케이크: 110MB → 1.3MB
- `file://`에서도 읽히도록 `assets/*.glb.js`(base64)로 감쌉니다. 지도 화면의 "모든 레벨을 Meshy 케이크로"로 전 레벨에 적용해 볼 수 있습니다.

## 구조

```
moakung3d/
  index.html            HUD · 개수 맞춤 바 · 오버레이
  js/rules.js           규칙·레벨·점수·최적 플레이 탐색(조기 실패 판정)
  js/world.js           three.js 장면, cannon-es 물리, 케이크 조각·모델 분할, 효과
  js/game.js            입력·판정·낙하·피날레·지도·도감·저장
  js/audio.js           WebAudio 효과음
  vendor/               three.min.js(0.158), cannon-es(0.20, 전역 래핑), GLTFLoader(전역 THREE 용으로 묶음)
  assets/               Meshy 케이크 GLB (+ base64 래퍼)
  tools/balance.js      레벨 성질 전수 검사
  tests/e2e.js          실제 마우스/터치 입력 검증 (Playwright, 소프트웨어 WebGL)
  docs/items.md         캐릭터 능력 → 아이템(부스터) 확장 설계
```
