# 모아쿵! v3 — 손맛 비교 목업 v0

**가설:** 친구들을 어떤 순서로 쌓을지만 고르고 탑을 밀어 넘어뜨리게 하면, 조준·계산·타이밍 없이도 누구나 첫 판에서 "쿵 쿵 쾅" 손맛을 느낀다(몽글탑).
다만 차별점은 아직 검증이 안 됐다. 그래서 처음 보는 손동작인 "원 그려 모아 쿵"(빙글쿵)을 나란히 두고 비교한다.

- 기획안 초안 v0.1: 컨셉 패널(관점이 다른 4안 × 기준이 다른 심사 3명)의 종합안. 뼈대는 몽글탑이다.
- 제작 루프: 기획안 초안 → 30분 목업 → 휴대폰으로 플레이 → 피드백 → 수정

## 실행
설치 없이 `moakung-v3/index.html`을 브라우저로 열면 된다. 각 목업은 HTML 파일 하나이고 외부 에셋이 없다(폰트만 Google Fonts).

| 파일 | 손동작 | 확인할 것 |
|---|---|---|
| `tower.html` A 몽글탑 | 언덕 친구를 톡톡(또는 쓱) 태워 쌓기 → 탑을 오른쪽으로 쓱 밀기(8° 이상에서 떼면 쿵) | 설명 없이 첫 쿵까지 가는가, 아이콘·떨림을 보고 스스로 순서를 바꾸는가 |
| `circle.html` B 빙글쿵 | 부술 곳 둘레에 동그라미를 빙글빙글 → 떼면 원 가운데로 쿵 | 돌리는 것 자체가 기분 좋은가, 원 안 물건이 같이 떨어진다는 걸 알아채는가 |

## 몽글탑 v0.2 규칙 (판 1개를 깊게)
**가설:** 친구를 한 번 쓰면 끝인 카드로 만들고, 무게와 바닥 면적에 따라 쌓을수록 흔들리게 하면 두 가지 긴장이 생긴다. 하나는 "누구를 지금 쓰고 누구를 아낄까"(머리), 다른 하나는 "하나만 더 올릴까?"(손)다.

- **친구 = 이번 판의 카드:** 꽝돌 3, 길쭉 3, 몽이 5, 부풀 1. 밀어서 쓴 친구는 쉬러 가서 다시 못 쓴다. 남은 친구가 곧 남은 기회다.
- **흔들림:** 이음새마다 `(위 무게 × 무게중심 높이) ÷ 받치는 폭`을 잰다.
  - 받침이 좁을수록, 위가 무거울수록, 높을수록 흔들린다.
  - 왼쪽 게이지(초록 → 노랑 → 빨강), 흔들림, 삐걱 소리, 땀 흘리는 친구로 보인다.
  - 한계를 넘으면 가장 약한 이음새 위가 뒤로 쏟아져 그 친구들을 잃는다.
  - 꼭대기를 톡 누르면 내릴 수 있다(손해 없음).
- **넘어지는 길:** 친구는 밑동을 축으로 원호를 그린다(점선). 앞에 원호보다 높은 벽이 있으면 거기 걸린다(빨간 점선).
  - 왕두더지(2칸 너비) 앞 벽은 꼭대기가 돌이라 꽝돌이나 부풀이 열어야 한다.
- **친구별 역할:**

| 친구 | 무게 | 바닥 | 하는 일 |
|---|---|---|---|
| 꽝돌 | 무거움 | 넓음 | 좋은 받침. 돌까지 2칸을 뚫는다. 양동이 1개를 벗기고, 4층 이상이면 한 방에 2개 |
| 몽이 | 가벼움 | 좁음 | 나무 깨기. 3층 이상이면 양동이 1개 |
| 길쭉 | 중간 | 좁음 | 높이를 올리는 사다리. 누우며 여러 칸의 나무를 친다 |
| 부풀 | 아주 가벼움 | 좁음 | 폭탄. 4층 이상이면 반경 2로 터져 벽을 부순다. 양동이는 못 벗긴다 |

- **연출:**
  - 8°를 넘는 순간 딸깍 소리와 진동이 난다.
  - 칸마다 재질별로 깨지는 소리가 따로 난다.
  - 마지막 일격에는 슬로모션, 왕두더지 쪽으로 줌, K.O.가 들어간다.
  - 별이 하나씩 소리와 함께 뜨고, 최고 기록은 `localStorage`에 저장된다.
- **별:** 남은 친구 3마리 이상 ★★★, 1~2마리 ★★, 0마리 ★
- **판 구성 근거(전수 탐색):** 최선은 친구 4마리를 남기고 2번 만에 승리한다.
  - 결정타는 "꽝돌·꽝돌·길쭉·부풀·꽝돌"(흔들림 0.997)로 양동이 2개를 벗기고, 이어 "길쭉·길쭉·몽이"로 끝낸다.
  - 무너지지 않는 첫 밀기 416가지 중 37%가 이길 수 있는 길로 이어진다.
  - 막 쌓은 6층 탑은 대부분 무너진다.
- **같은 규칙:** 미리보기, 실제 착지, 계산기는 같은 규칙 블록(`/*RULES-START*/ … /*RULES-END*/`)을 쓴다.
