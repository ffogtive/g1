# 모아쿵! v3 — 손맛 비교 목업 v0

**가설:** 친구들을 어떤 순서로 쌓을지만 고르고 탑을 밀어 넘어뜨리게 하면, 조준·계산·타이밍 없이도 누구나 첫 판에서 "쿵 쿵 쾅" 손맛을 느낀다(몽글탑).
다만 차별점은 아직 검증이 안 됐다. 그래서 처음 보는 손동작인 "원 그려 모아 쿵"(빙글쿵)을 나란히 두고 비교한다.

- 기획안 초안 v0.1: 컨셉 패널(관점이 다른 4안 × 기준이 다른 심사 3명)의 종합안. 뼈대는 몽글탑이다.
- 제작 루프: 기획안 초안 → 30분 목업 → 휴대폰으로 플레이 → 피드백 → 수정

## 실행
설치 없이 `moakung-v3/index.html`을 브라우저로 열면 된다. 각 목업은 HTML 파일 하나이고 외부 에셋이 없다(폰트만 Google Fonts).

| 파일 | 손동작 | 확인할 것 |
|---|---|---|
| `tower.html` A 몽글탑 | 언덕 친구를 톡톡(또는 쓱) 태워 쌓기 → 탑을 오른쪽으로 쓱 밀기(8° 이상에서 떼면 쿵) | 설명 없이 첫 쿵까지 가는가, 아이콘·떨림을 보고 스스로 순서를 바꾸는가 |
| `circle.html` B 빙글쿵 | 부술 곳 둘레에 동그라미를 빙글빙글 → 떼면 원 가운데로 쿵 | 돌리는 것 자체가 기분 좋은가, 원 안 물건이 같이 떨어진다는 걸 알아채는가 |

## 몽글탑 규칙 (화면에 글 없이 보이는 것)
- 떨어지는 칸 = 아래 친구들 키의 합 + 자기 키의 ½. 탑이 높을수록 멀리 간다.
  - 얼굴 아이콘이 그 칸 위에 뜬다.
  - 깨질 블록·두더지·양동이만 덜덜 떤다. 아무것도 못 깨는 친구는 아이콘이 흐리다.
- 몽이: 나무를 1칸 깨고, 3층 이상이면 2칸 이상 깬다.
- 길쭉: 키가 2.5칸이라 사다리 역할을 한다. 누우면서 2~3개 기둥의 나무를 1칸씩 친다.
- 꽝돌: 돌까지 아래로 2칸을 뚫는다. 왕두더지 양동이를 벗긴다.
- 왕두더지 양동이 3개를 다 벗기면 승리. 깃발(밀기) 5번을 다 쓰면 실패. 별 = 1 + 남은 깃발(최대 3).
- 첫 판의 미리 선 탑은 시연용이라 깃발을 쓰지 않는다. 친구는 넘어진 뒤 언덕으로 돌아와 다시 쓸 수 있다.
- 미리보기와 실제 착지는 같은 `simulate()` 결과를 쓴다 → 항상 일치한다.

## 검증
Playwright(Chromium 390×844, CDP 실제 터치)로 다음을 확인했다.
- 몽글탑: 시연 밀기, 8° 미만 취소, 톡·쓱 태우기, 꼭대기 내리기, 미리보기 = 실제(3번 연속), 승리(별 3), 실패, 콘솔 오류 없음 — 17/17
- 검증 API(읽기 전용): `window.mongle.snapshot()`, `window.binggle.snapshot()`
