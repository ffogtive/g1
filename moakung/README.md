# 모아쿵! — 캐주얼 게임 프로토타입

> **가설:** "단단함 임계값 + 낙하에 쓴 재료의 1/3 손실" 두 규칙만으로
> ① 강한 케이크부터 큰 덩어리 ② 약한 케이크엔 조금만 쓰고 아끼기 ③ 아무 순서로 전부 쏟기 = 실패
> 가 동시에 성립하고, 플레이어는 공식을 몰라도 조준 미리보기만 보고 고를 수 있다.

차르륵 쓸어 모아 → 하나로 뭉쳐 → 케이크 위에서 놓으면 자동으로 쿵! → 와르르.

## 실행

설치·서버 없이 `moakung/index.html`을 브라우저로 열면 됩니다 (파일 더블클릭 OK).
모바일 세로 화면과 데스크톱 마우스를 모두 지원합니다. 진행·도감은 브라우저 `localStorage`에 저장됩니다.

```bash
# (선택) 휴대폰에서 같은 와이파이로 열어 보기
npx http-server moakung -p 8080    # → http://<PC-IP>:8080
```

## 조작법

| 하고 싶은 것 | 조작 | 낙하 횟수 |
|---|---|---|
| 재료 쓸어 담기 | 빈 바닥을 **꾹 누른 채 문지르기** (점선 원 안의 재료가 덩어리로 붙음) | 그대로 |
| 케이크 부수기 | 덩어리를 **케이크 위로 옮겨 손 떼기** → 자동으로 들어 올려 쿵 | **1번 사용** |
| 잠깐 내려두기 | 케이크 **밖에서** 손 떼기 → 그 자리에 덩어리로 놓임 | 그대로 |
| 더 줍지 않고 옮기기 | 놓아둔 **덩어리를 잡고** 끌기 (옮기는 동안 재료를 줍지 않음) | 그대로 |
| 양 다시 고르기 | 놓아둔 덩어리를 **톡** → 흩어짐 → 다시 원하는 만큼 쓸어 담기 | 그대로 |
| 덩어리 키우기 | 쓸면서 놓아둔 덩어리 위를 지나가기 → 통째로 합쳐짐 | 그대로 |
| 취소 | `Esc`, 화면 밖에서 놓기, 터치 취소 → 떨어뜨리지 않고 덩어리로 놓임 | 그대로 |

조준하면 카드가 **한 번에 부서지는지 / 몸체가 몇 % 남는지 / 튀어나갈 재료 수와 남는 재료 수 / 몇 개면 충분한지**를 보여 줍니다.
케이크 아래 막대는 남은 몸체, 점 3개는 단단함입니다.

## 규칙 (rules.js)

- 스테이지마다 재료 50개, 낙하 4번, 케이크 3개. **케이크 몸체를 모두 부수면 성공** (부스러기 청소는 없음).
- 피해: 덩어리 `n`개, 케이크 단단함 `armor`일 때 `n > armor ? (n − armor) + 0.2·armor : 0.2·n`
  → 단단한 케이크는 작은 덩어리로는 *흠집만* 난다.
- 손실: 낙하에 쓴 재료 중 `round(n/3)`개가 쟁반 밖으로 튀어 사라진다. 나머지는 케이크 주변에 흩어져 다시 쓸 수 있다.
  쓰지 않은 재료는 그대로 보존. 케이크 파편은 재료를 보충하지 않는다(연출만).
- 잃는 개수는 충돌 순간 확정되고, 화면의 `재료/잃음` 숫자는 그 재료가 실제로 **쟁반 테두리를 넘는 순간** 하나씩 바뀐다(연출 = 수치).
- 재질(쇠구슬·너트·젤리·자개·단추·별)은 힘이 같고(1개 = 1), 모양·소리·튀는 모습이 다르다. 잘 튀는 재질(젤리, 쇠구슬)이 먼저 쟁반 밖으로 나간다.
- 남은 재료·횟수로 남은 케이크를 다 부술 방법이 없으면 바로 실패를 알려 준다(“그래도 계속” 가능).
- 별: 남은 재료 수로 ★1~3. 부순 케이크는 도감에 기록.

### 스테이지 설계

| 스테이지 | 케이크 (한 번에 필요한 개수) | 의도 |
|---|---|---|
| 1 오후의 티타임 | 커스터드 푸딩 8 · 딸기 쇼트케이크 21 · 초코 가나슈 33 | 입문. 강한 것부터 전부도, 아껴 쓰기도 승리. 약한 순 전부는 실패 |
| 2 생일 파티 | 레몬 무스 6 · 무지개 크레이프 17 · 3단 생일 케이크 38 | 전부 쏟는다면 3단 케이크부터만 승리 |
| 3 왕실 디저트 | 마카롱 탑 16 · 베리 치즈케이크 34 · 왕관 초코 타르트 36 | 어떤 순서든 전부 쏟으면 실패. 필요한 만큼만 써야 승리 |

`node moakung/tools/balance.js`가 이 성질을 전수 검사합니다(전략 × 순서 × 수거 오차 +0/+2/+4/+6).

```
moakung/
  index.html          레이아웃·스타일·HUD
  js/rules.js         순수 규칙·스테이지 수치 (Node에서도 require 가능)
  js/game.js          입력·상태·낙하 연출·판정·화면 전환·도감 저장
  js/art.js           케이크 9종·재료 6종 캔버스 벡터 그림, 손상 단계
  js/audio.js         재질별 WebAudio 효과음 (파일 없음)
  tools/balance.js    밸런스 전수 검사
  tests/e2e.js        실제 포인터/터치 입력 검증 (Playwright)
  docs/               캐릭터 확장 설계, 스크린샷
```
