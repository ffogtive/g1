# 킁킁! — 강아지 코 피하기 아케이드 (30분 목업)

**가설:** "바닥의 내 폰을 강아지가 위에서 들여다본다" 앵글(하늘 배경, 어안처럼 커다란 코)의 귀여움은 눈맞춤과 다가오는 코에서 나온다.
플레이어를 바닥의 작은 간식 쿠키로 두고, 거대한 코가 킁킁 다가오면 **쓱 끌어 피하거나 톡 코를 튕겨 내는** 단순한 아케이드로 만들면 누구나 3초 안에 이해한다.
코가 화면 유리에 찰싹 눌리는 순간, 재채기, 혀 날름이 웃음과 공유 포인트가 된다.

설치 없이 `index.html`을 열면 실행된다. 단일 파일이고, 캔버스 2D와 인라인 JS로 만들었다. 외부 에셋은 없고 폰트(Jua)만 쓴다.

## 조작
- **쓱 (피하기):** 화면 아래(바닥) 아무 데나 손가락을 대고 좌우로 끈다. 손가락이 아래에만 있어서 강아지를 가리지 않는다.
- **톡 (코 톡):** 코가 가까이 왔을 때(돌진 후반) 코를 누른다. 너무 일찍 누르면 아무 일도 없다.

## 한 번의 공격
| 단계 | 화면 | 판정 |
|---|---|---|
| 킁킁 (0.55초) | 콧구멍 벌름, "킁킁" 김, 바닥에 흰 점선 원이 쿠키를 늦게 따라옴 | — |
| 잠금 | 원이 빨갛게 고정 | 이때부터 비켜야 함 |
| 돌진 (0.42→0.28초) | 코만 어안처럼 커짐(눈·귀는 조금만) | 후반에 코 톡 가능 |
| 쿵 | 코가 유리에 찰싹 + 흔들림, 유리에 **코 도장** | 원 안이면 날름, 밖이면 피함 |

- **피함:** 강아지가 "??" 하고 갸웃한다. 점수는 +10이고, 연속으로 피하면 콤보로 더 붙는다. 아슬하게 피하면 "아슬!" +15가 붙는다.
- **잡힘:** "날름!" 큰 혀가 화면을 쓱 핥고 쿠키가 젖는다. 하트 −1이고, 하트는 3개다.
- **코 톡:** "에취!" 재채기를 하며 강아지가 물러난다. +30.
- **점점 어렵게:** 공격 간격이 1.6초에서 0.7초로 줄고 돌진도 빨라진다. 20초부터 가짜 킁킁(반쯤 오다 갸웃, 다시 노림)이 나오고, 35초부터 두 번 연속 킁킁이 나온다.
- **끝:** 결과 카드에 점수, 최고 기록, 피함·코 톡·코 도장 수, **날름당한 순간 한 컷**(캔버스 캡처)이 나온다.

## 검증 (Playwright, 390×844, CDP 실제 터치) — 19/19
1. 제목 화면에서 탭하면 시작한다.
2. 쿠키를 끌면 따라오고, 눈동자가 왼쪽·오른쪽으로 쿠키를 따라 본다.
3. 잠긴 뒤 비키면 피함 +점수에 하트는 그대로다. 코 도장이 남는다.
4. 가만히 있으면 날름(하트 −1)이고, 한 컷이 캡처된다.
5. 너무 일찍 누른 코 톡은 무시되고, 돌진 후반의 코 톡은 재채기 +30이다.
6. 자동 피하기로 40초를 버틴다. 가짜 킁킁은 20초 뒤에야, 두 번 연속은 35초 뒤에야 처음 나온다.
7. 하트 0이면 결과 카드, 최고 기록 저장, 날름 한 컷이 나오고, 다시 누르면 새 판이 된다.
8. 콘솔 오류 0.

- 테스트 재현용 시드: `index.html?seed=11`
- 읽기 전용 관찰 창: `window.kung.snapshot()`

## 실사 시험판 `real.html` v2 (AI 영상 클립 · 5칸 · 패턴 7종)
**가설:** "정면만 공격"으로 보인 건 강아지는 늘 정중앙으로 오고 영상만 밀었기 때문이다.
- 칸마다 그 방향으로 고개를 틀어 오는 클립을 고른다. 왼쪽 칸은 좌우 반전한다.
- 가짜·연타·멈칫은 같은 클립을 거꾸로 재생하거나, 멈추거나, 빠르게 재생해 만든다.
- 이렇게 하면 클립 몇 개로 그림 버전의 공격 패턴을 실사로 옮길 수 있다.

- **소재 (`real/`, 약 21MB)**
  - 모두 AI로 만들었다. 이미지는 Higgsfield gpt_image_2_5, 영상은 Seedance 2.5다.
  - 모든 클립은 같은 기준 사진에서 시작하고 같은 사진으로 끝난다. 그래서 클립을 바꿔도 이음새가 거의 없다.
  - 클립마다 WebM(VP9)과 MP4(H.264) 두 형식이 있다. 키프레임은 0.25초마다다. WebM은 Chromium용, MP4는 iPhone용이다.
  - `biscuit.webp`(실사 뼈다귀 비스킷)과 `grass.webp`(잔디 띠)는 배경을 로컬에서 색으로 빼냈다.

| 클립 | 장면 | 쓰임 |
|---|---|---|
| `sniff` | 평소 킁킁·갸웃·깜박 | 쉬는 동안 반복 |
| `press` (+`_rev`) | 정면으로 코를 렌즈에 꾹 | 가운데 칸. 옆으로 밀어 안쪽 칸(1·3)에도 씀 |
| `press_r1`, `press_r2` (+`_rev`) | 고개를 오른쪽으로 크게 틀어 꾹 | 바깥 칸(4). 반전하면 0칸 |
| `lick`, `lick_r1`, `lick_r2` | 같은 방향으로 렌즈를 핥는 강아지 뽀뽀 | 잡혔을 때. `lick` 3.0~3.8초는 가짜 뒤 "메롱" |
| `paws` | 앞발로 렌즈를 톡톡 | 앞발 콩콩(쿠키 쪽으로 반전) |
| `sneeze` | 찡긋 → 에취 | 코 톡 |

- **칸과 화면 맞춤**
  - 칸은 5개이고 화면 폭의 0.14 / 0.32 / 0.5 / 0.68 / 0.86 지점이다.
  - 코가 눌리는 자리(프레임 비율)가 목표 x에 오도록 영상 층을 민다. 확대까지 계산해 정하고, 최대 72px까지만 민다. 민 만큼 확대해 영상 가장자리가 안 보이게 한다.
  - 바깥 칸은 코가 원래 화면 끝 쪽에 닿기 때문에, 목표에서 0~40px 바깥에 닿을 수 있다(의도한 절충).
- **패턴과 시간표:** 판정 규칙은 그림 버전과 같다. 흰 원은 아직 안 아프고, 빨간 것만 아프다.
  - 0초 킁
  - 10초 크게 킁(원 96, 톡 +50)
  - 16초 가짜: 다가오다 거꾸로 → 메롱 → 진짜
  - 22초 멈칫: 영상이 멈춘 채 빨간 원이 슬금슬금
  - 27초 앞발 콩콩: 같은 자리 두 번
  - 32초 두 번
  - 42초 세 번: 연타 사이는 거꾸로 재생으로 빠르게 물러난 뒤 바로 다음 자리를 잠근다
- **검증:** `node kungkung/tools/e2e-real.js` — **35/35**. 로컬 HTTP로 열고 실제 터치로 확인한다.
  - 5칸 각각 맞는 클립과 반전이 쓰이고, 코 자리가 맞다(안쪽 칸 ±15px, 바깥 칸 같은 쪽 60px 안).
  - 7개 패턴 모두: 가만히 있으면 공격 하나에 정확히 한 번만 맞고, 빨간 구간 밖으로 피하면 다 피한다.
  - 가짜는 흰 원이고 판정이 없으며 톡이 무시된다. 거꾸로 재생과 메롱을 거친 뒤 빨강으로 바뀐다.
  - 멈칫 동안 원이 따라온다.
  - 코 톡은 재채기 클립이 나오고 +30, 크게 킁에서는 +50이다.
  - 버릇 시간표대로 패턴이 나온다.
  - 자동 피하기로 52초 동안 하트 3을 유지한다.
  - 결과 카드에 날름 한 컷이 나온다. 안전 구간 경고 0, 콘솔 오류 0.
