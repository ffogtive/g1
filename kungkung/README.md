# 킁킁! — 강아지 코 피하기 아케이드 (30분 목업)

**가설:** "바닥의 내 폰을 강아지가 위에서 들여다본다" 앵글(하늘 배경, 어안처럼 커다란 코)의 귀여움은 눈맞춤과 다가오는 코에서 나온다.
플레이어를 바닥의 작은 간식 쿠키로 두고, 거대한 코가 킁킁 다가오면 **쓱 끌어 피하거나 톡 코를 튕겨 내는** 단순한 아케이드로 만들면 누구나 3초 안에 이해한다.
코가 화면 유리에 찰싹 눌리는 순간, 재채기, 혀 날름이 웃음과 공유 포인트가 된다.

설치 없이 `index.html`을 열면 실행된다. 단일 파일이고, 캔버스 2D와 인라인 JS로 만들었다. 외부 에셋은 없고 폰트(Jua)만 쓴다.

## 조작
- **쓱 (피하기):** 화면 아래(바닥) 아무 데나 손가락을 대고 좌우로 끈다. 손가락이 아래에만 있어서 강아지를 가리지 않는다.
- **톡 (코 톡):** 코가 가까이 왔을 때(돌진 후반) 코를 누른다. 너무 일찍 누르면 아무 일도 없다.

## 한 번의 공격
| 단계 | 화면 | 판정 |
|---|---|---|
| 킁킁 (0.55초) | 콧구멍 벌름, "킁킁" 김, 바닥에 흰 점선 원이 쿠키를 늦게 따라옴 | — |
| 잠금 | 원이 빨갛게 고정 | 이때부터 비켜야 함 |
| 돌진 (0.42→0.28초) | 코만 어안처럼 커짐(눈·귀는 조금만) | 후반에 코 톡 가능 |
| 쿵 | 코가 유리에 찰싹 + 흔들림, 유리에 **코 도장** | 원 안이면 날름, 밖이면 피함 |

- **피함:** 강아지가 "??" 하고 갸웃한다. 점수는 +10이고, 연속으로 피하면 콤보로 더 붙는다. 아슬하게 피하면 "아슬!" +15가 붙는다.
- **잡힘:** "날름!" 큰 혀가 화면을 쓱 핥고 쿠키가 젖는다. 하트 −1이고, 하트는 3개다.
- **코 톡:** "에취!" 재채기를 하며 강아지가 물러난다. +30.
- **점점 어렵게:** 공격 간격이 1.6초에서 0.7초로 줄고 돌진도 빨라진다. 20초부터 가짜 킁킁(반쯤 오다 갸웃, 다시 노림)이 나오고, 35초부터 두 번 연속 킁킁이 나온다.
- **끝:** 결과 카드에 점수, 최고 기록, 피함·코 톡·코 도장 수, **날름당한 순간 한 컷**(캔버스 캡처)이 나온다.

## 검증 (Playwright, 390×844, CDP 실제 터치) — 19/19
1. 제목 화면에서 탭하면 시작한다.
2. 쿠키를 끌면 따라오고, 눈동자가 왼쪽·오른쪽으로 쿠키를 따라 본다.
3. 잠긴 뒤 비키면 피함 +점수에 하트는 그대로다. 코 도장이 남는다.
4. 가만히 있으면 날름(하트 −1)이고, 한 컷이 캡처된다.
5. 너무 일찍 누른 코 톡은 무시되고, 돌진 후반의 코 톡은 재채기 +30이다.
6. 자동 피하기로 40초를 버틴다. 가짜 킁킁은 20초 뒤에야, 두 번 연속은 35초 뒤에야 처음 나온다.
7. 하트 0이면 결과 카드, 최고 기록 저장, 날름 한 컷이 나오고, 다시 누르면 새 판이 된다.
8. 콘솔 오류 0.

- 읽기 전용 관찰 창: `window.kung.snapshot()`

## 실사 시험판 `real.html` v3 시험 — 잔디 구도에서 칸마다 "앙"
**가설:** v2에 타격감이 없던 건 카메라가 하늘을 올려다봐서 "아래로 = 렌즈 쪽"이었기 때문이다. 그래서 코가 화면 전체를 덮고 5칸이 무의미했다.
- 잔디가 보이는 낮은 구도로 바꾼다.
- 강아지가 칸마다 고개를 숙여 잔디 위 한 점(쿠키 자리)을 입으로 "앙" 물게 한다.
- 그러면 일러스트판처럼 딱 그 자리만 찍는 손맛과 "정확히 물려는" 긴장감이 산다.

- **소재 (`real/v3/`, 약 8.6MB)**
  - 기준 사진 1장(Higgsfield gpt_image_2_5)과 Seedance 2.5 앙 클립 2개다. 두 클립 모두 시작과 끝이 기준 사진이다.
  - 거꾸로 재생본과 대기 고리는 로컬 ffmpeg로 만들었다.

| 클립 | 장면 | 쓰임 |
|---|---|---|
| `snap_c` | 바로 앞 잔디로 고개를 숙여 혀를 내밀고 앙 → 잔디째 킁킁 → 고개 듦 | 가운데 칸 |
| `snap_r2` | 오른쪽 아래 잔디로 고개를 틀어 앙 | 오른쪽 칸. 반전하면 왼쪽 칸 |
| `*_rev` | 거꾸로 재생 | 피함·연타·가짜: 문 자리(또는 반쯤)에서 그대로 고개를 든다 |
| `idle` | `snap_c`의 가만히 서 있는 1.4초를 앞뒤로 이어 붙인 고리 | 평소와 예고(킁킁) |

- **칸:** 시험 단계라 3칸이다. 칸 = 클립에서 잰 "입이 잔디에 닿는 점"이다.
  - 바깥 칸은 영상 층을 최대 ±55px 밀어 맞춘다.
  - 영상은 늘 6% 크게 깔아 밀 여유를 만든다. 확대는 무는 순간의 펀치(1.03, 크게 킁 1.05)에만 쓴다.
- **무는 순간**
  - 히트스톱 0.06초(크게 0.08): 게임 시계와 영상만 멈추고 쿠키 끌기는 계속된다.
  - 무는 자리를 중심으로 줌 펀치를 주고, 영상과 그림을 같이 흔든다. "앙!" 글자, 풀잎·부스러기가 튄다.
  - 물리면 쿠키가 입 속으로 사라진다. 잔디째 냠냠한 뒤 고개를 들면 **잇자국**을 달고 퐁 다시 나온다(하트 3 = 잇자국 3).
  - 빗나가면 "앙?"이 뜨고 쿠키가 움찔한다.
- **패턴 6종**(앞발은 덮치기 클립이 생기면 다시): 킁 / 크게 킁 / 가짜 / 멈칫 / 두 번 / 세 번.
  - 멈칫은 입을 벌린 채 쿠키 바로 위에서 멈추고, 빨간 원이 칸 ±36px 안에서 슬금슬금 움직인다.
- **끊김 없는 영상 전환**
  - 숨긴 채 다음 시작점으로 미리 되감고(prime), 새 프레임이 준비된 뒤 위층만 0→1로 올린다.
  - 예고(킁킁) 중에는 클립을 바꾸지 않는다.
  - 판정은 게임 시계가 정하고, 영상은 따라가기만 한다.
- **코 톡 vs 쿠키 끌기:** 코 톡은 앙 진행 45~92% 구간에서, 쿠키보다 36px 위의 코를 눌렀을 때만 된다. 쿠키를 누르면 늘 끌기다.
- **소리**
  - `real/sfx/manifest.json`에 있는 샘플만 받아 쓰고, 없거나 깨진 것은 합성음으로 대신한다.
  - 샘플은 `node kungkung/tools/make-sfx.js gen` → `pick`으로 만든다(ElevenLabs 효과음 API).
  - 키에 "Sound Effects" 권한이 있어야 한다. 지금 키에는 권한이 없어 합성음이다.
- **검증:** `node kungkung/tools/e2e-real.js` (로컬 HTTP, 390×844, CDP 실제 터치)
  - 칸마다 무는 점이 칸 중심 ±12px·쿠키 높이 ±14px 안이다(실측 0px).
  - 그림을 숨긴 스크린샷에서 무는 점은 강아지 입이고, 반대쪽 칸은 잔디다.
  - 히트스톱 동안 게임 시계와 영상은 멈추고, 쿠키는 끌린다.
  - 물리면 쿠키가 숨었다가 잇자국 1개를 달고 다시 나온다.
  - 6개 패턴 모두 가만히 있으면 한 번, 피하면 다 피한다.
  - 가짜, 멈칫, 코 톡 +30/+50, 쿠키 탭은 톡이 아니라 끌기다.
  - 자동 피하기로 52초 동안 하트 3을 지킨다. 결과 카드에 "앙 물린 순간" 한 컷이 나온다.
  - 끊김 지표: 전환 첫 프레임 ±0.07초, 늦은 전환 0, 예고 중 전환 0, 화면 덮임 1, 보이는 층 되감기 0.
  - 소리 샘플 받기와 대체가 되고, 콘솔 오류는 0이다.
- v2(하늘 구도 5칸, `real/press*` 등)는 git 기록에 남아 있다. 5칸 완성 때 `real/`에서 옛 소재를 지운다.

## 아이폰 앱 (Flutter) — `app/`

**가설:** 검증된 웹 게임을 다시 짜지 않고, 앱 안 로컬 서버(영상 Range 지원)와 WKWebView로 띄우면 아이폰에서 그대로 돈다.

- 설치 순서(Mac + 유료 개발자 계정)는 [`app/README.md`](app/README.md)에 있다. 요약하면 `./tool/sync_web.sh` → `flutter pub get` → Xcode에서 팀 선택 → `flutter run --release`다.
- `real.html` 앱 대응:
  - `window.KungNative`(앱 채널)가 있거나 아이폰이면 영상은 mp4만 쓴다.
  - 진동 `buzz()`는 앱 햅틱으로 보낸다.
  - 일반 브라우저에서의 동작은 그대로다.
- 검증(Linux 컨테이너):
  - `flutter analyze` 0건, 서버 단위 테스트 7/7
  - 앱 서버 코드(`app/tool/serve.dart`)로 E2E 49/49: `BASE_URL=http://127.0.0.1:8790 node tools/e2e-real.js`
  - 앱 경로 점검: mp4만 쓰는지, 물리면 `buzz:40,30,60`이 앱으로 가는지
