# 킁킁! — 강아지 코 피하기 아케이드 (30분 목업)

**가설:** "바닥의 내 폰을 강아지가 위에서 들여다본다" 앵글(하늘 배경, 어안처럼 커다란 코)의 귀여움은 눈맞춤과 다가오는 코에서 나온다.
플레이어를 바닥의 작은 간식 쿠키로 두고, 거대한 코가 킁킁 다가오면 **쓱 끌어 피하거나 톡 코를 튕겨 내는** 단순한 아케이드로 만들면 누구나 3초 안에 이해한다.
코가 화면 유리에 찰싹 눌리는 순간, 재채기, 혀 날름이 웃음과 공유 포인트가 된다.

설치 없이 `index.html`을 열면 실행된다. 단일 파일이고, 캔버스 2D와 인라인 JS로 만들었다. 외부 에셋은 없고 폰트(Jua)만 쓴다.

## 조작
- **쓱 (피하기):** 화면 아래(바닥) 아무 데나 손가락을 대고 좌우로 끈다. 손가락이 아래에만 있어서 강아지를 가리지 않는다.
- **톡 (코 톡):** 코가 가까이 왔을 때(돌진 후반) 코를 누른다. 너무 일찍 누르면 아무 일도 없다.

## 한 번의 공격
| 단계 | 화면 | 판정 |
|---|---|---|
| 킁킁 (0.55초) | 콧구멍 벌름, "킁킁" 김, 바닥에 흰 점선 원이 쿠키를 늦게 따라옴 | — |
| 잠금 | 원이 빨갛게 고정 | 이때부터 비켜야 함 |
| 돌진 (0.42→0.28초) | 코만 어안처럼 커짐(눈·귀는 조금만) | 후반에 코 톡 가능 |
| 쿵 | 코가 유리에 찰싹 + 흔들림, 유리에 **코 도장** | 원 안이면 날름, 밖이면 피함 |

- **피함:** 강아지가 "??" 하고 갸웃한다. 점수는 +10이고, 연속으로 피하면 콤보로 더 붙는다. 아슬하게 피하면 "아슬!" +15가 붙는다.
- **잡힘:** "날름!" 큰 혀가 화면을 쓱 핥고 쿠키가 젖는다. 하트 −1이고, 하트는 3개다.
- **코 톡:** "에취!" 재채기를 하며 강아지가 물러난다. +30.
- **점점 어렵게:** 공격 간격이 1.6초에서 0.7초로 줄고 돌진도 빨라진다. 20초부터 가짜 킁킁(반쯤 오다 갸웃, 다시 노림)이 나오고, 35초부터 두 번 연속 킁킁이 나온다.
- **끝:** 결과 카드에 점수, 최고 기록, 피함·코 톡·코 도장 수, **날름당한 순간 한 컷**(캔버스 캡처)이 나온다.

## 검증 (Playwright, 390×844, CDP 실제 터치) — 19/19
1. 제목 화면에서 탭하면 시작한다.
2. 쿠키를 끌면 따라오고, 눈동자가 왼쪽·오른쪽으로 쿠키를 따라 본다.
3. 잠긴 뒤 비키면 피함 +점수에 하트는 그대로다. 코 도장이 남는다.
4. 가만히 있으면 날름(하트 −1)이고, 한 컷이 캡처된다.
5. 너무 일찍 누른 코 톡은 무시되고, 돌진 후반의 코 톡은 재채기 +30이다.
6. 자동 피하기로 40초를 버틴다. 가짜 킁킁은 20초 뒤에야, 두 번 연속은 35초 뒤에야 처음 나온다.
7. 하트 0이면 결과 카드, 최고 기록 저장, 날름 한 컷이 나오고, 다시 누르면 새 판이 된다.
8. 콘솔 오류 0.

## 실사 시험판 `real.html` (AI 영상 클립)
**가설:** 카메라가 바닥에 고정된 게임이라, 같은 프레임에서 시작하고 끝나는 실사 영상 클립을 상태마다 갈아 끼우면 젖은 코·혀 질감을 실시간 3D 없이 얻는다. 판정·조작은 그림 버전과 같고, 그림만 영상으로 바꿨다.

- **소재 (`real/`)**
  - 기준 사진 1장: 바닥에서 올려다본 회색 이탈리안 그레이하운드 강아지, 하늘 배경.
  - 클립 3개: 그 사진을 시작·끝 프레임으로 둔 5초 영상(720×1280, 24fps).
  - 모두 AI 생성(Higgsfield: 이미지 gpt_image_2_5, 영상 Seedance 2.5).
  - 형식: 클립마다 WebM(VP9)과 MP4(H.264) 두 가지. 키프레임은 0.25초마다(구간을 건너뛰어 재생하므로).
  - WebM은 Chromium용(Playwright의 Chromium은 MP4를 못 튼다), MP4는 iPhone 사파리용.

| 클립 | 쓰는 구간 | 장면 |
|---|---|---|
| `sniff` | 전체 반복 | 평소: 킁킁, 갸웃, 깜박 |
| `press` | 0.7–1.4 킁킁 → 1.4–2.5 돌진 → 2.5– 꾹 → 3.9–5.0 물러남 | 코가 렌즈를 덮고 유리에 눌림 |
| `lick` | 2.0–5.0 | 혀로 렌즈를 쓱, 입술 할짝, 원래 자세 |

- **흐름**
  - 평소에는 sniff를 반복한다.
  - 킁킁(흰 원) 단계에서 press의 0.7초부터 튼다.
  - 잠그면(빨간 원) 돌진 구간을 돌진 시간에 맞춰 빠르게 튼다. 이때 영상 층을 옆으로 밀어 코가 목표 위로 오게 하고, 민 만큼 코 중심으로 확대해 가장자리가 드러나지 않게 한다.
  - 쿵 순간 판정한다. 피했으면 press 물러남, 잡혔으면 lick을 튼다.
  - 클립 끝 프레임이 기준 프레임과 같아서 다시 sniff로 넘어갈 때 이음새가 없다.
- **검증:** `node kungkung/tools/e2e-real.js` — 12/12. 로컬 HTTP로 열고 실제 터치로 확인한다.
  - 영상 3개 로드
  - 클립 전환 규칙
  - 가운데와 왼쪽 목표 모두에서 코가 목표 x ±15px 안
  - 피하기, 날름, 코 톡 +30
  - 결과 카드에 영상 프레임을 합성한 날름 한 컷
  - 콘솔 오류 0
